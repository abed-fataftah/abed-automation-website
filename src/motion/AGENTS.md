# Motion

## Overview

All animation code for the site. The page must be complete and readable without anything here; this folder only adds GSAP motion (spec 0008) and the live dotted portrait in the hero (spec 0014) on top, loaded late and only when the visitor's settings and connection allow it. The lazy loading contract comes from spec 0001.

## Key files

| File | Owns |
|---|---|
| `loader.ts` | The only motion code in the first page load. Waits for `load` plus idle time, checks reduced motion and connection speed, then dynamically imports `gsap.ts` and `portrait.ts`. |
| `gsap.ts` | `init(root: HTMLElement): () => void`. The only file that imports `gsap`. |
| `portrait.ts` | `init(container: HTMLElement): () => void`. Draws the dotted portrait on a canvas over the still image and follows the pointer, taps, and booking button focus. The only file that imports `portrait-dots.json`. |
| `portrait-dots.json` | The portrait's dot data, generated by `docs/design/assets/make-portrait-dots.py`. |

## Conventions

- Import `gsap` only in `gsap.ts` and `portrait-dots.json` only in `portrait.ts`. Reach both modules only through `import()` in `loader.ts`, never a static import, so neither lands in the entry chunk.
- Keep the `init` signatures above. Each returns a cleanup function; the loader collects them and calls them all when reduced motion turns on mid visit. Turning it off mid visit does not restart motion.
- No content starts hidden in CSS while waiting for JavaScript. Any "from" state is set by the motion script itself after it loads.
- GSAP loads only when `prefers-reduced-motion: reduce` does not match and the page has a `[data-reveal]`, `[data-line]`, or `[data-underline]` hook.
- The portrait loads at every viewport width when reduced motion is off, the page has a `[data-portrait]` container, and `navigator.connection` does not report `saveData`, `2g`, or `slow-2g`.
- `DottedPortrait.astro` owns the `[data-portrait]` container and its still image. `portrait.ts` adds the canvas, and only after the first drawn frame gives it `role="img"` with the image alt as its label, hides the image from the accessibility tree, and fades it out. Its cleanup removes the canvas and restores the image.
- The portrait reads its colors from `--color-fg`, `--color-portrait-sclera`, and `--color-bg`; no hex values in `portrait.ts`. The `TUNING` values are approved; change them only with Abed's approval.
- The portrait runs no animation frame loop while the pointer is still or the canvas is off screen.
- Every dynamic import stays wrapped in `try`/`catch`; a failure logs one `console.warn` and leaves the static page untouched. No 2D context does the same.

## Gotchas

- Done check after any change here: `pnpm check && pnpm build && pnpm check:bundle`. `check:bundle` (part of `pnpm verify`) fails if GSAP, the portrait, or the dots data is reachable from an up front chunk, or if the portrait's gzipped import closure goes over its budget (`PORTRAIT_BUDGET_KB` in `scripts/check-bundle.mjs`).
- `gsap` 3.15.x is pinned with `~`; keep it on that minor unless a spec says otherwise.
- Print always shows the still image: `@media print` in `src/styles/global.css` hides the portrait canvas.
