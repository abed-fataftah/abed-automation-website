# 404 (not found)
Route: any unknown path (file `src/pages/404.astro`, layout `src/layouts/Base.astro`)
Purpose: tell the visitor the page is missing and send them to the home page.
Source in scope: spec 0001 (branded 404 page)
Design direction: I2, approved.

## Content (exact copy)
The source of every line is the approved *Copy deck* in [spec 0004](../../specs/0004-site-copy/index.md) (the `notFound.*` keys), copied into `src/content/site.ts`. Do not copy text from here; read the deck.

Header and footer are the same as the home page. Nav links go to `/#tools`, `/#services`, `/#about`. Footer Privacy link goes to `/#privacy`.

## Layout
Desktop (1280): header, 1px divider, content block (padding 48px top, 64px bottom): "404" (14px `muted`), title (hero style, 40px, max width 560px), body (16px `muted`, max width 460px), secondary button, then footer.
Tablet (768): same as desktop.
Mobile (390): header on two rows, title 32px, button full width, footer stacked.

## Components
| Element | Component | Variant | Notes |
|---|---|---|---|
| Code | `<p>` | 14px `muted` | Not a heading |
| Title | `<h1>` | hero size | One h1 |
| Back button | secondary button | 48px, 1px `fg` border | Links to `/` |

## Data
Static text from `src/content/site.ts`.

## States
Only one state: the page itself. The secondary button has default, hover, focus (see `design.md`).

## Interactions
1. Click "Back to the home page" → opens `/`.
2. Click a nav link → opens the home page at that section.

## Accessibility
One `<h1>`. Same landmarks as the home page. Netlify serves this file with HTTP status 404 (verify in feature 16). Set `<meta name="robots" content="noindex">`.

## SEO
Title: "Page not found | Abed Automation" (sample). No description needed. Not indexed.
